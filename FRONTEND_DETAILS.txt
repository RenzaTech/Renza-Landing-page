3.1 SPLASH SCREEN (`components/splash/SplashScreen.tsx`)
-------------------------------------------------------
* Purpose: Provides a cinematic first-load brand reveal without flashing unstyled content.
* Logic:
  - Checks `sessionStorage.getItem('renza_intro_seen')`.
  - If seen, skips animation immediately and displays the page.
  - If first visit:
    1. Dark background overlay `#071313` covers viewport (z-index 9999).
    2. RENZA 'R' logo mark scales in with back.out(1.5).
    3. Turquoise progress line scales from 0% to 100% over 1.2s.
    4. At 1.70s, dispatches `window.dispatchEvent(new CustomEvent('renza_splash_reveal'))`.
    5. Splash screen wipes upwards with power4.inOut, revealing the hero.
    6. Sets `sessionStorage.setItem('renza_intro_seen', 'true')`.

3.2 NAVBAR (`components/Navbar.tsx`)
------------------------------------
* Layout: Fixed header floating at the top of the viewport (`fixed top-0 left-0 right-0 z-50`).

    * Typography: Crisp pure white text (`text-white`), logo in white.

3.3 HERO SECTION (`components/Hero/Hero.tsx`)

4. ANIMATION SYSTEM ARCHITECTURE
================================================================================

4.1 GSAP PLUGINS & REGISTRATION
-------------------------------
* Registered plugin: `gsap.registerPlugin(ScrollTrigger)`
* Client-Side Guard: `if (typeof window !== 'undefined')` ensures server-side rendering (SSR) safety.
* Cleanup Pattern: Every GSAP animation is scoped inside `gsap.context((self) => { ... }, containerRef)` and returned in `return () => ctx.revert()`. This guarantees zero memory leaks during page navigation or Hot Module Reloading (HMR).

4.2 ANIMATION CATEGORIES
------------------------
1. Cinematic Carousel Transitions:
   - incoming slide: `clipPath: inset(0% 0% 0% 100%) -> inset(0% 0% 0% 0%)`, `scale: 1.08 -> 1.0`, `x: 40px -> 0`, `opacity: 0 -> 1` over 1.5s (`power4.inOut`).
   - outgoing slide: `scale: 1.05`, `x: -30px`, opacity fade over 1.4s.
   - Ken-Burns zoom: `scale: 1.0 -> 1.04` over 5.5s (`sine.out`).
2. Mouse Parallax Engine:
   - Uses `gsap.quickTo` for 60fps hardware-accelerated pointer tracking on desktop.
   - Computes relative pointer coordinates `relX = (clientX - rect.left) / width - 0.5`.
3. SVG ScrollTrigger Path Drawing:
   - Dynamically calculates `getTotalLength()`.
   - Scrubs `strokeDashoffset` from `pathLength` down to `0` based on scroll progress.
4. 3D Flip Card Transitions:
   - CSS 3D transforms (`rotateY(180deg)`) coupled with GSAP scroll-triggered stagger entrance.

6. ACCESSIBILITY & PERFORMANCE STANDARDS
================================================================================

* Reduced Motion: Respects user preference `(prefers-reduced-motion: reduce)`. Replaces clip-path wipes and parallax with gentle cross-fades and disables continuous zoom.
* Semantic HTML: Valid HTML5 structure using `<header role="navigation">`, `<main id="landing-page-content">`, `<section aria-labelledby="...">`, `<button>`, `<svg>`, `<nav>`, `<footer>`.
* Image Optimization: Next.js `<Image>` component utilizing modern WebP formats, responsive `sizes="100vw"`, explicit image dimensions, and priority flags on critical above-the-fold assets.
* Zero Layout Shifts (CLS): High-priority hero image containers, fixed heights for carousel stages, and aspect-ratio preservation prevent Cumulative Layout Shifts.
* Responsive Breakpoints:
  - Mobile:      < 640px (compact stacked inputs, 100svh hero, vertical timeline)
  - Tablet:      640px - 1023px (2-column grids)
  - Desktop:     >= 1024px (full alternating S-curve, mouse parallax, 3-column grids)
  - Ultrawide:   >= 1280px (constrained via container-renza max-w-7xl)
